Rehman-PDF portable mode

While this file sits next to RehmanPDF.exe, Rehman-PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the RehmanPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Rehman-PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Rehman-PDF and
%LOCALAPPDATA%\Rehman-PDF) instead. If RehmanPDFData can't be written (for example on a read-only
drive), Rehman-PDF says so and uses the per-user folders instead.
